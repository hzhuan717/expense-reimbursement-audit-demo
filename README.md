# 费用报销智能审核 Demo

财务共享中心费用报销流程的静态网页演示。上传发票图片后，浏览器内的 OCR 会尝试提取发票号码、价税合计、开票日期和销售方，并根据票面内容给出费用类型建议。系统再检查发票号码、费用限额和模拟真伪，将异常单据交给人工复核。

## 使用

在浏览器打开 `index.html`，或访问本仓库的 GitHub Pages 网站。无需构建工具或服务器。记录存储在浏览器本地。

选择 PNG、JPG 或 WebP 发票图片（最大 8 MB），页面会自动开始识别；也可点击“识别示例发票”体验。首次识别会从 jsDelivr/unpkg 下载 Tesseract.js 7.0.0 OCR 引擎及简体中文模型，需联网。引擎在浏览器内运行，图片不会上传到本网站；CDN 会收到静态资源请求。OCR 结果可能出错，提交前请逐项核对；扫描件、反光、模糊或复杂版式会降低识别率。

## 演示规则

- 交通费上限 500 元、住宿费 800 元、餐饮费 300 元、办公用品 1000 元。
- `FP-HIST-001` 是模拟历史发票；重复提交的发票号码也会被识别。
- `FP-FAKE-001` 返回模拟结果“疑似伪票”；其他号码模拟为“真票”。
- OCR 只负责从图片提取文字和字段，不判断发票真伪，也不保证字段准确。
- 额度与真伪结果均为教学模拟，不连接真实税务、企业财务或制证系统。不要录入个人、真实发票或财务数据。

申请记录仅保存在使用者自己的浏览器本地存储中，不会通过本 Demo 上传到服务器。
